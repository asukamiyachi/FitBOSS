# 実験種目

トレーニング画面でスクワットとプランクを選べます。どちらも試験的な2D姿勢判定で、正しいフォームや運動効果を判定するものではありません。側面から肩・腰・膝・足首が見える位置を試し、痛みや疲労があれば中止してください。

- スクワット：左右いずれかの腰・膝・足首から膝角度を求め、上下の動作を仮にカウントします。角度の閾値は腕立て実験と同じ仮の値で、実際の動作に合わせた校正は未実施です。
- プランク：肩・腰・膝が概ね一直線かつ横向きに検出された区間の時間を秒表示します。検出できない間やフレーム間隔が長い場合は加算しません。姿勢の正確さを保証せず、測定精度も未検証です。
- 2種目は画面表示のみ。履歴に保存せず、対戦進捗やFirebaseにも送信しません。種目変更時に実験値をリセットします。腕立ての従来の保存・送信処理はそのままです。

合成フレームで正常動作・部分動作・低信頼・追跡欠落・時刻異常を検証しています。実人物・様々な体格や撮影条件での精度評価は未実施です。
