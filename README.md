# FitBOSS

FitBOSS is a macOS-native exercise pose-analysis project.

> Initial repository bootstrap. See the camera-and-pose MVP pull request for the experimental app.

## Development scope

- First: on-device camera capture, Apple Vision pose landmarks, exercise-evaluator interface, and reproducible experiments.
- Later, in separate tracks: game experience, online matches, team registration, and leaderboards.

No game features or online backend are included in the camera MVP.
